# Student Assignment Management System

A beginner-friendly BCA project using PHP, MySQL, HTML, CSS and JavaScript.

## Features
- Responsive login and registration
- Student and teacher roles
- Assignment dashboard
- Teachers can publish assignments
- Students can submit answer text
- MySQL schema included

## Run locally with XAMPP
1. Copy this folder to `C:\xampp\htdocs\student-assignment-system`.
2. Start Apache and MySQL.
3. Import `database.sql` using phpMyAdmin.
4. Open `http://localhost/student-assignment-system/`.

## Important
This is a starter project and needs testing before real use. Do not store real student data in a public repository. Configure database credentials in `config.php` for your environment.
